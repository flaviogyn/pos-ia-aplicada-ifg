## **Atividade principal**
1. Construa ou pesquise um dataset de imagens, em tons de cinza, de dois tipos diferentes de animais, exemplo gato/cachorro ou galinha/vaca (conjunto de imagens para treinamento e teste);
2. Pesquise sobre como transformar imagens em entradas para um Perceptron e faça a conversão;
3. Utilize o Perceptron que você implementou em sala para treinar o data set e classificar entre os dois tipos;

  Obs.: preferencialmente em Python.

## **Entregáveis esperados:**
- Dataset bruto
- Dataset normalizado (formato csv)
- Algoritmo de normalização (comentado)
- Código do Perceptron
- Relatório do trabalho desenvolvido, justificando com base em literatura confiável (PDF)
